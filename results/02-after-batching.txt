# ЧТО СДЕЛАНО
# Раньше каждый прямоугольник рисовался отдельным вызовом
# SDL_RenderFillRect, и перед каждым менялся цвет через
# SDL_SetRenderDrawColor. При 128 врагах это 512 вызовов заливки
# + 512 смен цвета на кадр.
# Теперь прямоугольники копятся в буферы по цветам, и за кадр
# выполняется 10 вызовов SDL_RenderFillRects - по одному на цвет.
# Также 100 вызовов SDL_RenderDrawPoint на звёзды заменены
# одним вызовом SDL_RenderDrawPoints.

# ВАЖНОЕ НАБЛЮДЕНИЕ
# Значение present (~4.1 мс) - это НЕ работа программы, а ожидание
# вертикальной синхронизации монитора (240 Гц). Оно не зависит от
# числа объектов и не поддаётся оптимизации.
# Реальная работа программы - это work = update + fill:
#   0.058 мс "до"  и  0.012 мс "после".
# При бюджете кадра 16.6 мс (60 FPS) игра использовала 0.35% бюджета.
# Вывод: на 128 врагах производительность не является узким местом;
# для дальнейших измерений нагрузку необходимо увеличить.
