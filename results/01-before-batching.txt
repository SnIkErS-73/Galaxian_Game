# Процессор: AMD Ryzen 9 9900X, 32 ГБ ОЗУ
# ОС: Windows 11
# Конфигурация: Release, x64
# Сценарий: HARD (8x16 = 128 врагов), 32 пули в полёте, 600 кадров
# Запуск: главное меню -> клавиша B

Замер 1:
enemies=128 bullets=32 frames=600 update_ms=0.0036 draw_ms=4.1550 total_ms=4.1586

Замер 2:
enemies=128 bullets=32 frames=600 update_ms=0.0039 draw_ms=4.1520 total_ms=4.1559

Замер 3:
enemies=128 bullets=32 frames=600 update_ms=0.0036 draw_ms=4.1525 total_ms=4.1560

# Средние значения:
# update_ms (обновление логики) = 0.0037 мс   -  0.09% кадра
# draw_ms  (отрисовка)          = 4.1532 мс   - 99.91% кадра
# total_ms (кадр целиком)       = 4.1568 мс
#
# ВЫВОД: узкое место - отрисовка. На кадр приходится:
#   128 врагов x 4 прямоугольника = 512 вызовов SDL_RenderFillRect
#   + 512 вызовов SDL_SetRenderDrawColor
#   + 100 вызовов SDL_RenderDrawPoint (звёзды)
# Итого ~1100 вызовов SDL API на один кадр.
