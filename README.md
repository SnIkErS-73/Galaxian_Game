# Galaxian

Клон классической аркады **Galaxian** на **C** и **SDL2**. Курсовая работа по языку C: враги летят строем и пикируют на игрока, три уровня сложности, таблица лидеров, демо-режим, где играет бот.

## Возможности

- Строй врагов, который сдвигается и опускается к игроку; случайные враги выходят из строя и пикируют, стреляя по пути.
- Три уровня сложности (количество врагов, скорость, множитель очков).
- Ввод имени в аркадном стиле: три буквы, выбор из алфавита.
- Таблица лидеров (топ-10), сохраняется в `leaderboard.dat`.
- Режим **AI vs AI**: бот сам выбирает цель, двигается и стреляет.
- Меню, экран Game Over с выбором Replay / Menu.


## Управление

| Экран | Клавиши |
|---|---|
| Главное меню | `↑` `↓` или `W` `S`, выбор: `Enter` / `Space` |
| Ввод имени | стрелки или `WASD` выбирают букву, `Enter` / `Space` вводит, `Backspace` удаляет; после трёх букв `Enter` продолжает |
| Выбор сложности | `←` `→` или `A` `D` переключают, `Enter` подтверждает |
| Игра | `←` `→` движение, `Space` выстрел, `Esc` выход в меню |
| Game Over | `↑` `↓` выбор, `Enter` подтверждает |

## Сложность

| Режим | Врагов | Скорость строя | Очки за врага |
|---|---|---|---|
| Easy | 12 (3×4) | 1 | 100 |
| Normal | 20 (4×5) | 2 | 200 |
| Hard | 32 (4×8) | 3 | 300 |

## Сборка

Нужно: **Visual Studio 2022** (17.10 или новее, формат решения `.slnx`) с компонентом «Разработка классических приложений на C++». Платформа только **x64**.

1. Клонировать репозиторий:
   ```
   git clone https://github.com/SnIkErS-73/Galaxian.git
   ```
2. Открыть `Galaxian.slnx`.
3. Выбрать конфигурацию `Debug` или `Release`, платформу `x64`.
4. `Ctrl+F5`. SDL2 и SDL2_ttf лежат в папке `libs`, DLL копируются рядом с `.exe` после сборки автоматически.

Шрифт берётся из `arial.ttf` рядом с `.exe`, а если его нет, то из `C:\Windows\Fonts\arial.ttf`.

## Структура проекта

```
Galaxian/
├─ Galaxian.slnx
├─ Galaxian/            исходники и проект Visual Studio
│  ├─ main.c            WinMain, переключение состояний игры
│  ├─ game.c            игровой цикл, ввод, коллизии, экран Game Over
│  ├─ enemy.c           строй врагов, пикирование, победа
│  ├─ player.c          корабль игрока
│  ├─ bullet.c          пули
│  ├─ ai_player.c       бот для режима AI vs AI
│  ├─ difficulty.c      уровни сложности
│  ├─ menu.c            меню и таблица лидеров
│  ├─ name_input.c      ввод имени
│  └─ render.c          рисование (прямоугольники, текст, звёзды) через SDL2
├─ libs/                SDL2, SDL2_ttf
└─ screenshots/         скриншоты для README
```
